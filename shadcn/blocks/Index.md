# shadcn Blocks

收录官网 Blocks 首页及固定上游注册表的全部 30 个 Base UI block。独立预览采用 Nova。官网首页包含其原有的 New York 预览。

每个场景使用 1440 × 1000 的 Chromium 桌面视口，采集深浅色。 [采集记录](provenance.json)
